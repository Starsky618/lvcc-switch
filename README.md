# 明向充电空位

面向同学的静态共享查询页面。打开即查询明向校区固定 15 台充电桩；无需登录、GitHub Token 或后台服务器。手动刷新；可选择页面可见时每 30 秒自动刷新，默认关闭。隐藏或关闭页面会停止查询。本页面不发送微信提醒。

## 查询与数据边界

- 浏览器仅向 `https://appapi.lvcchong.com` 发起匿名 POST：`/appBaseApi/nearbyDeviceListWithoutLogin` 和 `/portDetail`。不发送 Cookie、Authorization、GitHub 请求或任何个人凭据。
- `site-config.js` 只包含站点名称/坐标，以及允许查询的设备 ID、sim ID、完整名称、短名称；由个人监测仓库 `targets.json` 和 `site.json` 提取这些字段而来。不得复制 `.local`、通知配置、账号或密钥。
- 每轮先查列表；仅有空位的候选设备再查插座明细，最多 2 个并发，请求起始间隔至少 1 秒。列表空闲数为 0 时只显示“暂无空闲插座”，不推断逐个插座是占用、故障还是停用。
- 明细必须与白名单设备 ID、名称、sim ID 一致；校验在线、设备状态、故障、总插座数和空闲数。真实插座从索引 1 开始，索引 0 是占位符。0/1/-1/-2 分别表示空闲/占用/故障/停用。
- 返回上游结果时仅提取设备可用性，不保留 ownerId、iccid、订单信息或其他多余字段；不把响应写入本地存储或日志。
- 请求超时、离线、身份不匹配和缺失设备均标为未知。超过 30 秒的设备结果也变为未知，且不再显示空闲。新一轮清空旧结果，取消及版本检查防止旧请求覆盖新结果。
- HTTP 403/405/429 会终止本轮后续请求、关闭自动刷新并退避；默认 5 分钟，若提供 Retry-After 则采用 1 分钟至 1 小时范围。恢复后需手动刷新，不循环重试。网络错误不会在同一轮重试。
- 目前没有已充时长、实时功率或充满时间数据，页面不猜测或显示预测值。

两个接口当前支持跨域匿名读取；此能力依赖上游接口与 CORS 行为。若上游关闭匿名访问或更改字段，页面会显示未知，不会改用个人凭据。多个同学访问会各自发起查询，本实现不提供集中缓存。

## 原个人提醒的保留方式

个人后台提醒仍由私有仓库 `Starsky618/lvcc-alert` 的 GitHub Actions `watch.yml` 执行，可在私有仓库 Actions 页面按原方式启动/停止。共享页不再提供这些控制，不会启动、停止或读取私人任务。

页面加载会分别尝试删除 localStorage 和 sessionStorage 中旧的 `lvcc-controller-key`，不读取其值。删除浏览器存储不等于撤销 GitHub Token；旧凭据的账户端撤销由迁移负责人在新入口验收后单独处理。

旧微信链接中的 `run` / `attempt` 不再读取私有历史。页面会明确提示已切换当前查询，避免把新结果误认为原提醒记录。

## 本地验证

无构建步骤、无新增依赖。Node.js 原生测试覆盖接口校验、部分失败、超时、限流、过期、旧请求失效及页面匿名查询路径：

```sh
node --test tests/*.test.cjs
python3 -m http.server 4173
```

浏览器打开 `http://localhost:4173/` 验证实际跨域请求。发布前还应在 320px / 390px 宽度检查完整名称、空位、刷新、旧链接说明及无横向溢出；真实接口结果应与本轮返回值核对。测试使用合成数据，不触发微信或 GitHub Actions。
